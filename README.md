# Pre-entrega-6---An-lisis-de-Datos-Meteorol-gicos-con-DuckDB-e-SQL
Análisis de datos meteorológicos de 3 estaciones argentinas usando DuckDB para consultar un CSV directamente, sin base de datos tradicional. Incluye limpieza de nulos, promedios mensuales, máximos históricos y conteo de días de helada, con tiempos de respuesta documentados.
